# Dashboard Files

This folder contains the primary Excel dashboard and operational reporting files used within the Operational Performance Dashboard project.

The dashboard was developed in Microsoft Excel to centralize workforce KPI reporting, operational analytics, quality monitoring, attendance tracking, and coaching workflow management.

## Contents

- KPI dashboard workbook
- Workforce performance tracking
- Attendance monitoring systems
- QA reporting tools
- Coaching workflow documentation
- Operational reporting templates

## Key Functional Areas

- Schedule adherence monitoring
- Average handle time (AHT) tracking
- Attendance escalation management
- Quality assurance reporting
- Coaching opportunity tracking
- KPI scorecards and trend analysis
